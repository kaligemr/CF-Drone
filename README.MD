# ESP32无人机飞控固件
* 该仓库仅为个人使用，无经营性。
* 提交很随意，想push就push，有bug或者代码写一半也会提交，请勿直接使用仓库代码！

## 适配硬件
* 已适配ESP32/ESP32-S3
* 支持6500/9250姿态传感器
* 完美适配琛光E1系列无人机
